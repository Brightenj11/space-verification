A few practical notes:

* These commands **do not** create train/val/test splits.
* They also **do not** create mixed 50/75/95 files, because each run uses one `--source-cases` value.
* `--panel-x-m` is a **post-processing standoff proxy**. It changes geometric acceptance and TOF, but it does **not** rerun Geant4 with a different physical spacecraft layout.
* The `high_gt60` / `low_gt60` regimes use your AP9 spectral shape and rescale it above 60 MeV. That is a useful approximation, but it is not a true time-resolved AP9 spectrum.

The two commands I’d run first are **Tier 0** and **Tier 5B**. That gives you one clean easy set and one clearly hard set, which is a good bracket for early ML baselines.
